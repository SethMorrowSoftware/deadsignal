▓ WELCOME

This is an offline forge for analogue-horror, cyberpunk and vaporwave media. Everything renders in your browser and downloads to your machine — nothing is uploaded.

  1. Make a look. Pick a Scene on VIDEO, or a template on SCREEN, and dial in the decay. Every control explains itself — press ? then click one.
  2. Export it. ● RECORD writes a .webm or .mp4 — the File picker chooses — faster than real time. Audio renders to .wav, screens to .png.
  3. Ship it. The BUNDLE tab turns your library into campaign-ready files and a drop-in .zip.

Lost? Ctrl+K searches every setting, scene and action by name.

The sample is a finished 10-second clip — a keyframed decay, a stacked digital-rain layer and a stereo bed — set up so you can change one thing and see what it does.

HOW TO USE

Offline, no dependencies, no network. Serve tools/media-studio/ from any static server — python -m http.server in that folder is enough — and open it. A browser will not load ES modules straight off the filesystem, which is why it is served rather than double-clicked; nothing is uploaded and everything renders locally and downloads to your machine.

  1. VIDEO — pick a Scene, tune the CRT/VHS stack + text, preview (scrub to any frame), then Record .webm. Export runs offline and faster than real time — a 10s clip takes about a second — and does not need the tab focused. Also exports animated .gif and a frame-strip. Bring your own art: ⇪ IMG (Ken Burns) or ⇪ VID — import a video clip (or drop one on the preview) and run it through the whole CRT/VHS + reveal/subliminal stack, then re-export. Plays natively in the campaign.
    Keyframes: scrub to a time, set a control, press ◆ KEY — two keys make a ramp, so a look can build or decay across the clip. Layers: stack up to six more scenes over the base, each with its own blend and opacity.
  2. AUDIO — enable layers + a master FX bus (reverb / delay / distortion / wow-flutter / bitcrush / telephone), Render, check the peak meter, optionally Normalize, download .wav (8/16/24-bit). Renders in stereo: every layer has its own pan, drone voices spread across the field, and a mid/side width control sits last on the bus. ⇪ AUDIO imports your own recording and runs it through the same FX bus.
  3. SCREEN — choose a Win95/CRT/paper template, apply CRT or paper-aging FX, embed a stego/hidden-channel token, export .png (1–4× supersample) or degraded .jpg. Import your own art with ⇪ IMG.
  4. TIMELINE — cut several scenes into one clip: set up a look on VIDEO and press ＋ SCENE, or a screen on SCREEN and press ＋ STILL; then edit on the track — drag a block to reorder it, drag its edge to trim it, click to select. Each clip enters on its own transition (cut / crossfade / dip-to-black). Record sequence → one .webm in the library, exported offline like a single clip.
  5. LIBRARY — name each asset, set gated + release beat.
  6. BUNDLE — pick the campaign target (which campaign, which release beats), generate the manifest/index/release wiring, validate it against that campaign's contract, or download a drop-in .zip.
    Import your campaign's current files (media-manifest.json, both index.json, autoexec.retro) and the bundle contains the complete merged result — installing becomes an overwrite instead of hand-editing JSON, and release lines you already have are left out of the snippet.

Sound on a clip: the Sound picker on VIDEO muxes an audio track into the exported .webm — the last AUDIO render, or any .wav in the library. A bed shorter than the clip loops to fill it, a longer one is trimmed, and the console says which happened. It travels in the recipe, so it is captured into a timeline clip and restored with the project. Leave it — silent — and export behaves exactly as it always did.

Three animated stills: .gif, .apng and .webp sit together on VIDEO and share one frame rate. GIF is 256 colours and one bit of transparency — it survives because it plays absolutely everywhere. APNG is lossless, 24-bit, with real alpha: the archival one. WebP is 24-bit with real alpha at a fraction of the size of either — the one to upload. All three are capped at 640px, because these are for a message or a post and a lossless 1080×1920 animation is a download nobody wants.

The waveform is an editor: drag a range on the wave and apply an edit — silence, fade in/out, gain, reverse, or crop to the selection. Edits are part of the project rather than a destructive button: they undo, they save, and every render replays them, so the same project always produces the same wave. They apply in order, each addressing the buffer as it then is — which matters only for crop, the one that changes the length.

RESET, LOAD and BATCH: RESET means the whole tab — the filter chain, layers, keyframes, audio FX, region edits, solo and screen marks go with the sliders, in one undo. LOAD backfills: a project older than a control resets that control to its default rather than leaving it at whatever you last set, so the look a file gives you never depends on what was on screen before you opened it. BATCH renders from recipes and never from the controls, for both document chains — a screen batch no more picks up your marks than a video batch picks up your filter chain.

Type: text can be left, centred or right aligned — the caret follows the type, so right-aligned text still ends in a cursor. Letterspace is letter-spacing as a percentage of the type size, so the same setting looks right on a small caption and a large title; negative values tighten. It is set once per frame beside the typeface, so every string a scene or template draws takes it. Zero touches nothing at all, so an older project is unchanged.

Aesthetic packs: the aesthetic switch reskins the tool and sets a palette; ◆ PACK beside it goes the rest of the way — it loads that world's starting preset on VIDEO, AUDIO and SCREEN as well, in one undo. Each aesthetic also names the scenes and screens that belong to it, so those two pickers group them at the top under the aesthetic's name with everything else underneath. Grouped, never filtered: a horror screen in a cyberpunk project is a legitimate choice and every one of the 48 scenes and 46 screens is still one scroll away.

Preset gallery: ⊞ beside any preset picker opens a grid of every preset in the list. On VIDEO and SCREEN each card is a real render at your current seed — the same path the export uses — showing what you get when you click it (the tab defaults with the preset over the top, exactly as loading applies it). AUDIO gets a contents list instead of a picture, because forty waveforms at that size are forty grey bricks; the card names the layers and effects the preset switches on. It starts closed, renders a few cards per frame, and redraws when you roll a new seed.

Marks (SCREEN): every template bakes its own layout, which is what makes them one-click and also why a caption could not be moved. Marks are the layer that is not baked — text, box, redaction, ellipse, line and arrow, placed over any of the 46. Add one and drag it on the preview; drag its corner grip to size it. Positions are fractions of the canvas, so a resize or an aspect change keeps them where you put them, and marks draw under the CRT pass — they are on the screen, not on the glass. No pointer needed: click a mark's name in the list and the arrow keys nudge it, Shift+arrow moves further, Alt+arrow resizes.

Solo: every layer has an S button beside its enable box — press it to hear only that layer, or a few to hear only those. The arrangement is never touched: the enable boxes keep what you set them to and clearing solo brings the whole mix back exactly. It undoes like everything else. It does apply to export, because here the render is the export — which is why an amber banner appears while anything is soloed and every soloed render prints a warning naming what was audible.

Batch export: on the LIBRARY tab. Export every VIDEO preset as a short clip, every SCREEN preset as a .png, or every TIMELINE clip on its own — trimmed exactly as you cut it. Each source shows how many files that is before you commit. Your own settings are not touched: a batch renders from recipes rather than from the controls, so exporting forty-five presets leaves your work, your undo history and your document exactly as they were. Sec each caps how long video items run, because a batch is a contact sheet — set it to 0 for full length. STOP keeps everything already exported.

MP4: the File picker on VIDEO and TIMELINE chooses the container. WebM plays in any browser; MP4 (H.264) is the one to hand to anything that is not a browser — a phone, an editor, an upload. H.264 is a licensed codec and some browser builds ship without it: those get a WebM and a line in the console saying why, rather than a failure or a file that claims to be an MP4 and is not.

The audio FX chain: the master bus is fixed — one control each, always in the same order. FX CHAIN is the part you order yourself, and it is the same panel as the video filter chain: pick one, ＋ FX, ↑ ↓ to reorder, ◉ to bypass, ✕ to remove. 3-Band EQ, Chorus / Flanger, Auto-Pan, Ping-Pong Delay, Pump / Gate, Stutter, Reverse Sections and Pitch Shift. An empty chain changes nothing, so anything you made before it sounds the same.

Sound layers: 26, each with its own pan and all through the same master FX bus. Beside the originals (drone, noise, pulse train, Morse, sub-bass, heartbeat, geiger, DTMF, dial-up) are Vinyl Crackle, Room Tone, Rain, Wind, Mains Hum, Clock Tick, Water Drip, Siren, Radio Tuning, Fax / Handshake, Answering Machine, Tape Stop, Tape Rewind, Breathing, Bell and Reversed Whisper. A layer that places a sound at a time you chose — the beep, the tape stop — extends the render to fit. ⊟ TIDY folds away everything switched off.

Scenes: 48 of them, from Terminal and Snow through the instrument panels (Radar, Sonar, Satellite Tracking, Dashcam, Vitals Monitor, CCTV Multiplex) and the device screens (VHS On-Screen Display, Teletext Page, Split-Flap Board, Keypad / Access, Elevator Indicator, IRC Log, Kernel Panic, Station Sign-Off) to the screensavers (Bouncing Logo, Pipes, Mystify, Starfield, Tunnel, Sine Scroller). Every one is animated, draws something at every time you can scrub to, and takes the text and background colour you set — the abstract screensavers excepted, which have nothing to caption.

Screens: 46 templates. Beside the Windows chrome (BSOD, dialogs, Explorer, Task Manager, Registry) is a shelf of paper — Newspaper Clipping, Police Report, Evidence Tag, Journal Page, Prescription, Boarding Pass, Bank Statement, Certificate, Calendar Page, Autopsy Form, Blueprint, Punch Card, Map with Pins, Floppy Label, CD Label — the props a player actually picks up. Paper templates fill with their own stock and ignore the background colour, because a newspaper on a green CRT background is not a newspaper; their type scales with the sheet, so a clipping at 1080×1920 is a readable page rather than a stamp of text in the corner.

The filter chain: the CRT/VHS stack is fixed — one control each, always in the same order. FILTERS is the part you order yourself: pick one, ＋ FILTER, and it runs after the built-in stack. ↑ ↓ reorder, ◉ bypasses without losing the settings, ✕ removes; up to eight steps, and an empty chain changes nothing. 45 filters across Colour, Sharpness, Analogue, Pattern and Frame — including Levels, Gradient Map, Retro Palette (Game Boy, CGA, EGA, Teletext, C64), NTSC Composite, Error Diffusion, ASCII, Kaleidoscope, Risograph, Tilt Shift, Neon Edge, Lower Third and Timecode Burn. Order is where most of a look lives: grading before a crush is a different picture from crushing before a grade.

Editing a sequence: a clip is a window onto its source, not the whole of it — trimming changes which part plays, never how fast. Drag a block on the track to reorder it or drag its edge to trim it; select one and use ←/→ to trim (Shift for 1s) or Alt+←/→ to reorder. A whole drag is one undo. The table under the track writes the same clips, for when you would rather type 4.25 than aim at a handle. ＋ STILL holds the current SCREEN render, which is how a title card or a document gets into a sequence. Sound on TIMELINE comes in two: the picker above the table covers the whole sequence, and the sound column gives each clip its own, laid over the top at the time that clip starts. Each clip's bed loops or trims to fit that clip, and moves with the picture when you trim or reorder.

Delivering somewhere: Format (on VIDEO, SCREEN and TIMELINE) sets the frame to a real delivery size — Shorts / TikTok / Reels is 1080×1920, and there are square, feed-portrait and YouTube sizes beside it. Aspect is the other half: it keeps the size you chose and reshapes the frame, now including 9:16 and 4:5. Editing W or H by hand puts Format back to custom. Both axes go to 1920; the size readout beside the preview estimates the export from what a frame actually costs, and .gif is capped at 640px because the format cannot carry more.

Text variables: a campaign fact, named once. Add subject = M. WEBB under TEXT VARIABLES (on VIDEO or SCREEN — it is one shared list) and write {{subject}} in any text box on any tab. Built-in names you can redefine: {{time}} {{case}} {{badge}}. Always available: {{date}} {{seed}} {{random:###}} {{pick:a|b|c}}. A name you have not defined is left on screen exactly as typed, so a typo is visible rather than silently blank.

Presets that keep your words: tick lock on a section and neither Randomize nor loading a preset will touch it. Lock TEXT and you can try every look in the list while your script stays put; lock OUTPUT to keep the delivery size you settled on. The ⚙ beside each preset picker renames, duplicates, deletes, exports and imports your own saved presets.

Layers stack up to six more scenes over the base. Each one can carry its own text, colour and size — open own text / look on a layer — and a variant number re-rolls that layer's randomness, so a second Digital Rain is a different rain rather than the first one twice. Leave a field empty and the layer follows the clip below it.

Typeface picks the family everything is drawn in — Monospace for a terminal, Heavy for a poster, Handwritten for a note left on a door. Wrap breaks a line too long for the frame instead of letting it run off the edge; it is off by default so older clips render exactly as they did, and your own line breaks are always kept.

Every settings section folds away — click a section title to collapse it and keep the panel tidy.

Finding things: Ctrl+K searches every setting, scene, template, preset and action by name and jumps straight to it. ? arms Explain mode — click or focus any control to read what it does, its range and its unit. The detail selector (Simple / Studio / Deep) hides advanced controls without changing their values.

Accessibility: the contrast selector turns off the CRT overlay and phosphor glow in the interface — your rendered media is byte-identical either way. The flash readout beside the preview measures full-screen luminance changes the way WCAG 2.3.1 defines them and turns red above three per second; it warns rather than blocks, since the strobing is usually deliberate here.

Determinism: the seed drives all randomness — same seed + params reproduces the same look (PNG/WAV are byte-stable; WebM frame-patterns reproduce but bytes may vary). Presets: the ✚ buttons save the current tab to your browser (localStorage); SAVE PROJ downloads the whole session's recipes as JSON.

Format note: browser capture is .webm and audio is .wav — both play natively in the campaign, no conversion. For exact .mp4/.mp3 parity use scripts/gen-campaign-media.py.
